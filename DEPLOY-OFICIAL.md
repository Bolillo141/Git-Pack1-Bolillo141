# Bolillo Optimizer — publicación oficial

Dominio objetivo: **bolillooptimizer.com**

Esta carpeta ya está preparada para producción y futuras actualizaciones.
Incluye SEO, sitemap, robots.txt, favicon, manifest, datos estructurados y CNAME.

## Flujo recomendado

1. Registrar `bolillooptimizer.com` a nombre del propietario de Bolillo Optimizer.
2. Subir esta carpeta a un repositorio GitHub, por ejemplo `bolillooptimizer-web`.
3. Activar GitHub Pages para la rama principal.
4. Configurar el dominio personalizado `bolillooptimizer.com` en Pages.
5. En el registrador, crear los registros DNS que indique GitHub Pages.
6. Activar HTTPS.
7. Dar de alta `https://bolillooptimizer.com/` en Google Search Console.
8. Enviar `https://bolillooptimizer.com/sitemap.xml`.

## Futuras actualizaciones

El dominio NO cambia. Para actualizar precios, reseñas, textos, imágenes o secciones:

- editar estos mismos archivos;
- subir la nueva versión al mismo repositorio;
- GitHub Pages publica la actualización sobre el mismo dominio.

Mantener copias etiquetadas como `PROD-v1`, `PROD-v2`, etc. permite volver atrás si una actualización da problemas.

## Importante

Un dominio no se puede "guardar" sin registrarlo. La reserva efectiva ocurre cuando se compra/registra y se renueva cada año.
