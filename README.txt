BOLILLO OPTIMIZER 141 — WEB V2
==============================

Cambios principales de esta versión:
- Mascota oficial de Bolillo integrada en header, hero, resultados y CTA.
- Overlay animado permanente a partir de "bolillo visual vf.mov", convertido a WebP transparente y optimizado para web.
- Eliminado el bloque/cartel de precios.
- Nueva sección de resumen técnico: 300+ reglas/acciones disponibles, 36 claves Warzone y módulos adaptativos.
- Nueva sección BOLILLO AI DIAGNOSTICS centrada en diagnóstico, validación y explicación de Applied / Skipped / Warning.
- Fondo cuadriculado más liso, sin textura granulada.
- Iluminación global azul + amarilla que sigue el puntero con desenfoque suave.
- Responsive para escritorio, tablet y móvil.

IMPORTANTE SOBRE LA IA:
La web describe un flujo de diagnóstico asistido: el optimizador local detecta hardware, aplica/omite módulos y genera logs/reportes; una capa de IA puede ayudar a interpretar esos reportes durante la sesión. Los cambios reales se ejecutan localmente por los scripts del optimizador.

Archivos principales:
- index.html
- styles.css
- script.js
- assets/mascota-bolillo-cutout.webp
- assets/mascota-bolillo.png
- assets/bolillo-overlay.webp

Para previsualizar:
Abre index.html en Chrome/Edge. Para publicar, sube toda la carpeta manteniendo la estructura.

RESEÑAS DE TIKTOK
-----------------
La sección de reseñas está preparada para comentarios reales del video:
https://www.tiktok.com/@bolillo141oficial/video/7587006701144952084

TikTok no expone públicamente el contenido de los comentarios a esta herramienta,
por lo que no se agregaron usuarios, fotos o reseñas inventadas.

Para publicar una reseña real en la web:
1. En TikTok, abre el comentario.
2. Usa Compartir comentario > Copiar enlace.
3. Guarda la foto/avatar como archivo local en assets/reviews/.
4. Añade name, handle, text, avatar y url en reviews.js.

El enlace directo del comentario es importante para que al pulsar la tarjeta se abra
la reseña original y no solo el video.
